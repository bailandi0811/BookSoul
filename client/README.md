# BookSoul Client

React 19、TypeScript、Vite、Zustand、Tailwind CSS 与 Framer Motion 构建的私人阅读助手界面。

登录后的顶栏提供「书友客厅」入口，`#community` 打开独立公共聊天页。首次加入须同意公开昵称和消息；私人书库、助手对话及记忆不进入聊天室。原生 WS 的票据、恢复和缓存由独立 community API/store 管理，书架和阅读页逻辑不变。移动端入口放在顶栏下方，避免挤占账号及外观操作。详情见[聊天室验收记录](../docs/community-chat-acceptance.md)。

构建后可从仓库根目录运行 `node client/test/verify-community-browser.cjs`，用隔离 Edge 与内存 HTTP/WS 夹具检查实际页面；该脚本不连接应用后端、不加载 `.env`，截图保存在 gitignored 的 `.superpowers/sdd/2026-10-04-community-chat/browser/`。它不能替代真实数据库或生产代理验收。

## 回答模式

聊天页与阅读器助手的“本次选项”提供快速/深度单选，默认快速，发送后保持当前模式，切换书籍/会话或重新打开面板后恢复快速。快速为普通混合 RAG；深度为 Agentic 混合 RAG，按需要补检或调用工具，最终回答通过 SSE 逐段输出。等待时显示阶段状态，可以“停止生成”；预算或依据不足时显示“依据有限”。模式与助手设置中的回答详略独立。

深度支持本书记忆、授权联网和邮件草稿，联网选项由用户本次明确选择，发送后清除。防剧透范围由单独的本次授权决定。失败和停止状态不会显示为已完成检索；`runSummary` 只存在本次流式消息，不作为新的历史存储字段。接口与验证状态见[Agentic 模式验收](../docs/agentic-reading-revision-acceptance.md)。


前端包含：

- 登录后的私人书架，以及 EPUB/TXT 上传、状态轮询、失败重试和可靠删除提示；
- 书库 → 本书空间 → 独立阅读或现有单书聊天；正文按窗口加载，并提供目录、排版、续读位置和可收起的阅读助手；
- SSE 内容、引用与记忆更新，以及请求级中断和竞态隔离；
- 默认防剧透和单次全书检索放行；
- 回复邮件按钮和模型 `prepare_email` 工具事件；工具只生成可编辑草稿，确认后才发送；
- 桌面可调侧栏、移动端抽屉、暗色主题和系统减少动态效果支持；
- 加载、空、失败与重试状态。

界面采用“AI 藏书室”的黑白灰纸面与织纹书封，书库、认证、单书助手、对话及邮件草稿共享排版和状态反馈。七张既有图片保留为系统壁纸，来源与使用条件见[背景素材说明](public/backgrounds/README.md)。默认随机模式在刷新或重新进入时从系统壁纸和本人图库抽取，候选多于一张时避免立即重复；站内切页、资料刷新和上传新壁纸不重抽。固定模式可选择系统图、本人图片或纯色纸面，登录用户的选择随账号保存；删除当前固定图片时原子恢复随机。亮暗主题独立保存在 `booksoul_theme`，本机仅缓存避免重复所需的图片标识，不保存私人签名 URL；存储不可用时当前页面仍可选择。书架外层采用透明纸面，正文与表单保持不透明，避免背景影响阅读。

首页在平板及手机上将书封、续读卡和功能说明按顺序排布，避免浮动卡片遮挡；手机使用紧凑标题、并排阅读入口和安全区留白，预览卡面跟随亮暗主题。

封面使用灯塔、月下书页、时钟、植物四套构图与配色，按上传时间依次轮换，比例为 3:4；显示排序和新增较晚上传的书籍不影响已有封面，同一本书在书架与工作区保持一致，当前页面删除其他书籍后也不会改变；封面绑定随私人书库状态清除，不保存额外用户数据。桌面四列、手机两列，书架显示真实藏书和阅读统计。手机使用紧凑输入区和导航抽屉，账号、进度、助手设置和原文引用按需展开，检索选项收在“本次选项”中。流式回复仅在读者停留底部时自动跟随，上翻阅读时可通过“最新回复”回到底部；中文输入法确认文字不会触发发送。系统减少动态效果设置会取消书本倾斜和持续动效。

点击顶栏账号进入 `#account` 账号设置页，桌面双栏、手机单栏，显示个人信息、邮箱验证状态、账号安全和书房外观。邮箱只在账号页或验证表单显示；可返回书库、打开背景菜单、补验证、找回密码或退出登录。找回密码预填当前邮箱，只有提交表单才发送申请，失败状态可重试。账号页同样受登录恢复校验保护。主动登录或注册成功后回到书架并清除残留的 `#account`；已登录用户刷新账号页时保留当前页。

账号页支持修改本人名称、更换或恢复默认头像；背景菜单可上传、选择和删除最多 20 张个人壁纸。原图通过无账号凭据的跨域请求直传 OSS，服务端验证并规范化后才更新资料。私人图片采用短时签名读取，退出或切换身份立即清除旧图和在途请求；版本冲突显式要求核对重试。未配置 OSS 时上传不可用，但名称和系统壁纸设置仍可使用。部署前提和本地验证见[资料与图片验收记录](../docs/user-profile-media-acceptance.md)。

阅读进度通过圆角章节列表选择，点击“保存书签”后才更新，取消保留原进度；方向键切换候选、Enter 确认、Escape 先收起列表。提问选项点击“应用到本次提问”后生效，取消丢弃未确认的设置。设置、原文引用、邮件草稿和删除确认共享纸面弹窗与开合动效；关闭后恢复触发按钮焦点并保留侧栏滚动位置，系统减少动态效果时取消位移与缩放。

阅读页采用独立圆角卡面：桌面左侧是书籍、目录与续读位置，中央是章节导航和一张不透明正文卡，右侧是工具与按需展开的助手；目录收起后仍保留书籍与位置摘要。所有章节在同一张正文卡内部连续滚动，章节标题保留，章节之间不拆成卡片；手机改为底部工具栏和弹层。上下滚动可连续跨章，临近章末预取下一章，回看时按需加载前章；正文最多保留 3 个窗口，预取不会淘汰当前可见文字。“续读位置”是下次打开的精确位置，可以停在更早的章节；正常阅读保存到更后的章节时，书架上的已读进度和助手讨论范围一起抬到该章，并按整章计算。目录和引用跳转先作为预览，只有选择“从这里继续阅读”才采用新位置并可能推进进度。回看前文不会把进度倒退。排版、目录和助手开合保持文字锚点；卡面悬停、按钮按压与面板开合提供短时反馈，并遵循系统减少动态效果设置，正文不随滚动做入场动效。字号、行距和正文宽度保存在本机，正文与续读位置不会写进浏览器长期存储。[合成浏览器验收](../docs/reader-acceptance.md)不需要真实后端。

注册时在当前页输入邮箱的 6 位验证码；登录页提供找回密码入口，账号页提供不阻塞使用的补验证。重置邮件链接优先进入改密页，读取后清除地址中的 Token，只在页面内存保存；成功后清认证和私人缓存，再普通登录。旧账号缺少验证字段按未验证展示。

本地交互测试与真实邮件 / 数据库验收分别记录，见[认证验收记录](../docs/auth-email-acceptance.md)。

登录后顶部“心绪塔罗”（`#tarot`）进入独立页面，先提问，再由自动分类或自行选择一张／三张牌阵。78 张本地牌背支持键盘选牌，小屏可滑动牌带；翻转、勾选、悬停与面板动效遵循减少动态效果设置。解读失败保留牌面和传统牌义，可用原局重试。离开、重新占卜或账号变化取消请求并清空状态，塔罗数据不进入 Web Storage。静态牌组以 `shared/tarot/deck.json` 为源，运行仓库根目录 `node scripts/sync-tarot-deck.mjs` 同步两包数据；公开牌图来源在 `public/tarot/README.md` 和 `sources.json`。实际验证见[塔罗验收记录](../docs/tarot-acceptance.md)。

刷新令牌不进入 Zustand、Local Storage 或前端响应类型。所有 API 请求使用 `credentials: include` 携带 HttpOnly Cookie；Access Token 过期时统一静默刷新，同一页面和支持 Web Locks 的同源标签页会串行轮换，避免把并发续期误判为令牌重放。聊天 body 不发送角色、owner 或 book id。

启动时的会话恢复最多等待 10 秒，包含跨标签页锁、认证请求和响应正文读取；失败后显示错误及手动重试入口，验证成功前不进入私人书架。刷新请求也有 10 秒上限，超时会取消请求并释放锁；单个调用方取消等待不会中断其他调用方共享的刷新。临时网络或服务故障保留已有凭据，只有服务端确认刷新凭据无效才清除登录状态。
