# BookSoul Client

React 19、TypeScript、Vite、Zustand、Tailwind CSS 与 Framer Motion 构建的私人阅读助手界面。

## 命令

```bash
npm ci
npm run dev
npm run check
npm run build
```

前端包含：

- 登录后的私人书架，以及 EPUB/TXT 上传、状态轮询、失败重试和可靠删除提示；
- 单书工作区、目录、阅读进度、按书会话和助手设置；
- SSE 内容、引用与记忆更新，以及请求级中断和竞态隔离；
- 默认防剧透和单次全书检索放行；
- 回复邮件按钮和模型 `prepare_email` 工具事件；工具只生成可编辑草稿，确认后才发送；
- 桌面可调侧栏、移动端抽屉、暗色主题和系统减少动态效果支持；
- 加载、空、失败与重试状态。

界面采用“AI 藏书室”的黑白灰纸面与织纹书封，书库、认证、单书助手、对话及邮件草稿共享排版和状态反馈。每次刷新或重新进入，从七张风景、城市和动漫壁纸中随机选择，避免立即重复；站内切页保持当前背景，可以手动切换壁纸或纯色纸面。亮暗主题独立保存在 `booksoul_theme`，`booksoul_background` 记录上次背景用于避免重复；存储不可用时仍可在当前页面切换。图片只从本地资源加载，来源与使用条件见[背景素材说明](public/backgrounds/README.md)。书架外层采用透明纸面，正文与表单保持不透明，避免背景影响阅读。

封面使用灯塔、月下书页、时钟、植物四套构图与配色，按上传时间依次轮换，比例为 3:4；显示排序和新增较晚上传的书籍不影响已有封面，同一本书在书架与工作区保持一致，当前页面删除其他书籍后也不会改变；封面绑定随私人书库状态清除，不保存额外用户数据。桌面四列、手机两列，书架显示真实藏书和阅读统计。手机使用紧凑输入区和导航抽屉，账号、进度、助手设置和原文引用按需展开，检索选项收在“本次选项”中。流式回复仅在读者停留底部时自动跟随，上翻阅读时可通过“最新回复”回到底部；中文输入法确认文字不会触发发送。系统减少动态效果设置会取消书本倾斜和持续动效。

点击顶栏账号进入 `#account` 账号设置页，桌面双栏、手机单栏，显示个人信息、邮箱验证状态、账号安全和书房外观。邮箱只在账号页或验证表单显示；可返回书库、打开背景菜单、补验证、找回密码或退出登录。找回密码预填当前邮箱，只有提交表单才发送申请，失败状态可重试。账号页同样受登录恢复校验保护。主动登录或注册成功后回到书架并清除残留的 `#account`；已登录用户刷新账号页时保留当前页。

阅读进度通过圆角章节列表选择，点击“保存书签”后才更新，取消保留原进度；方向键切换候选、Enter 确认、Escape 先收起列表。提问选项点击“应用到本次提问”后生效，取消丢弃未确认的设置。设置、原文引用、邮件草稿和删除确认共享纸面弹窗与开合动效；关闭后恢复触发按钮焦点并保留侧栏滚动位置，系统减少动态效果时取消位移与缩放。

注册时在当前页输入邮箱的 6 位验证码；登录页提供找回密码入口，账号页提供不阻塞使用的补验证。重置邮件链接优先进入改密页，读取后清除地址中的 Token，只在页面内存保存；成功后清认证和私人缓存，再普通登录。旧账号缺少验证字段按未验证展示。

本地交互测试与真实邮件 / 数据库验收分别记录，见[认证验收记录](../docs/auth-email-acceptance.md)。

刷新令牌不进入 Zustand、Local Storage 或前端响应类型。所有 API 请求使用 `credentials: include` 携带 HttpOnly Cookie；Access Token 过期时统一静默刷新，同一页面和支持 Web Locks 的同源标签页会串行轮换，避免把并发续期误判为令牌重放。聊天 body 不发送角色、owner 或 book id。

启动时的会话恢复最多等待 10 秒，包含跨标签页锁、认证请求和响应正文读取；失败后显示错误及手动重试入口，验证成功前不进入私人书架。刷新请求也有 10 秒上限，超时会取消请求并释放锁；单个调用方取消等待不会中断其他调用方共享的刷新。临时网络或服务故障保留已有凭据，只有服务端确认刷新凭据无效才清除登录状态。
