# 单书混合检索实现与验收记录

日期：2026-10-05。本记录描述当前实现；真实外部服务验收与质量评测尚未完成。

## 行为

Milvus 继续按可信用户/书籍/索引版本/阅读上限召回向量候选。BM25 从 PostgreSQL BookChunk 读取同范围的全部可见块，在应用内评分；全书未读内容、其他书及旧版本均不进入词法 N/df/avgdl。读取使用 RepeatableRead 快照并在查询层关联核对 Book 的归属、可见性、READY 和有效版本，检索完成后再次复核状态。

当前 profile 为 `visible-han-bigram-latin-v1`：中文连续汉字按重叠双字切分，单字汉字保留为单字，非汉字字母数字按连续词切分，使用 NFKC 与小写规范化。无需字典或新依赖，但不能保证单字查询匹配词内汉字，也不提供别名映射或严格短语匹配。

BM25 参数 k1=1.2、b=0.75。沿用现有 Planner 查询集合和每查询 `min(50, 2 × 最终片段数)` 候选量；两路内部保留原多查询融合，再以等权 RRF（k=60）融合通道。并列优先保留原向量次序、词法次序，最后用 chunkId。此策略是初始实现，未宣称最优或质量增益；不能将 RRF 分数解释为置信度。公开 score 保持数值类型，有词法结果时语义变为融合排名分数。

最终片段数、章节分散、重叠去重、上下文字符预算及引用格式沿用现有流程。问候无检索。两路任一异常均拒绝本次检索，不静默降级。

## 资源与取消

- 可见语料最多 10,000 块、16 MiB UTF-8 正文，分页每次 250 块。
- 读取阶段预算 5 秒，事务 timeout 8 秒/maxWait 2 秒；词法分词与评分阶段另有 5 秒预算。
- 超过预算明确返回不可用错误，不截取部分语料伪装完整 BM25，也不扩大阅读范围。长书已读完可能触发上限，这是当前实现的容量限制。
- 无正文缓存、持久词法索引、新迁移或补建任务；既有上传、READY、失败重试和删除流程不因词法索引变化。
- 词法循环定期让出事件循环并检查取消；任一检索分支失败会停止另一分支的后续阶段与重试。
- 当前 LangChain Embeddings 接口不接受 per-call AbortSignal，Milvus 调用使用现有请求超时：已发出的远端请求不能保证即时取消，但取消后不启动新阶段、不重试、不返回迟到结果。PostgreSQL 已发出的查询由事务超时收束，取消后不继续读取分页。

## 验证记录

相关 Jest 已覆盖：手算 BM25、完整可见统计、专名与混合文字、重复词、取消、向量无命中词法补召回、查询层隔离、SYSTEM scope、跨页证据、状态变化拒绝、预算失败不降级与失败分支收束。外部依赖均使用 mocks，不加载数据库集成测试。

独立审查发现的混合文字漏召回及失败后继续调用问题已各自通过 RED → GREEN 回归修复，另补充单个长片段分词期间的取消回归。

最终 `server npm run check` 成功（exit 0）：lint 无错误、有 44 条现存警告；TypeScript 检查通过；86 个 Jest 套件、553 项测试全部通过；Nest 构建成功。默认 `jest --listTests` 已确认排除数据库集成测试；认证测试禁用 .env 加载并覆盖外部 provider。仅本次文件的 Prettier 检查与 `git diff --check` 通过。

本机 npm 启动 shim 指向缺失入口，验证改用已安装 npm 的 CLI，并在子进程中设置 npm_config_prefix 后执行原有 check 脚本；没有安装工具或修改用户 npm 配置。

合成内存评分探针（每个规模 5 次、三条查询）：200/2,000/10,000 块，对应 0.144/1.44/7.2 MB UTF-8。最终实现测得中位耗时为 7/49/281 ms，最大耗时为 13/54/359 ms。该测量未包含 PostgreSQL、Embedding、Milvus 或真实并发；不能用于宣称整次请求 p95 或真实召回提升。

未运行真实 PostgreSQL/Milvus reader E2E：未核验独立测试库与向量目标，也未启动实际 worker 或把用户正文发送到新目的地。未完成多书固定题集相对当前纯向量路径的召回/语义退化/融合消融验收；原 +10 个百分点等目标不作为已达成结论。

## 后续验收

使用明确隔离的 *_test 数据库/test_* schema、独立 test_* 向量集合和允许使用的语料验证真实查询性能与集成边界。冻结当前 Planner 输出、向量候选、语料与预算作为纯向量 B0，再分别比较词法补召回、等权/向量偏重融合与最终证据组覆盖；单列逐题改善/退化和配对不确定性。若真实长书容量不足，再评审作用域内持久词频或倒排方案，不新增全局 IDF 或隐式单路降级。
