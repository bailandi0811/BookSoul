# BookSoul 交互设计预览

[打开翻书动效 HTML](open-book.html)。点继续阅读或书架上的任意一本，封面从被点中的位置移到正文左侧，目录和纸页随后出现；点「回到书房」或按 Esc 沿原路返回。右上角可切换「整页淡出」，对照现在的屏幕切换。预览不请求网络。

[打开书友客厅 HTML](community-chat.html)。将文件用浏览器打开即可使用；CSS、脚本、插画和背景图片都包含在单个 HTML 内，预览不请求应用 API，不连接数据库，不上传内容。摄影素材沿用仓库的海边背景，来源链接保留在背景菜单。

## 设计方向

这是独立的书友交流页面。沿用 BookSoul 的纸面、墨色、宋体标题与胶囊导航，加入 Summer 式的场景氛围。主要创意集中在右侧书桌插画：摊开的书、热茶和围坐的座椅；点击茶杯可以填入一段问候草稿，三个书脊开场也只填入文字，由用户决定是否发送。手机隐藏辅助栏，把空间留给聊天。

核心颜色是纸白 `#F5F5F2`、纸页 `#FBFBF8`、墨色 `#242424`、雾绿 `#476451`、旧书金 `#B18D49`、灰蓝 `#738B9B`。标题沿用项目宋体字体栈，品牌使用 Georgia，正文使用本机中文无衬线字体；不依赖在线字体。

## 可以体验的操作

- 输入消息，Enter 发送、Shift+Enter 换行；支持输入法组合与 2000 字符限制。
- 点“回复”引用消息，点引用定位原消息；自己的消息可通过确认框撤回。
- 点表情插入 Unicode 文本；在桌面点开场书脊或茶杯填入草稿。
- 滚到较早消息，再点底部“模拟新消息”，观察阅读位置保持和新消息提示。
- 点“体验发送失败”，发送一条消息后点“重新发送”，验证不会出现两个气泡。
- 在“我的书库”和“书友客厅”之间切换，草稿保留；书库页面仅提供导航示例。
- 切换日读/夜读、海边/纸面背景；点聊天室信息按钮查看公开身份与加入说明。

## 边界

所有昵称、对话、书籍和在线人数均为模拟内容。加入确认框演示交互，预览默认展示已加入状态；关闭或刷新会丢失演示数据。真实鉴权、未读持久化、发送限流、跨设备同步、管理员能力、数据库幂等和 WS 重放仍按[设计契约](../superpowers/specs/2026-10-04-community-chat-design.md)与[实施计划](../superpowers/plans/2026-10-04-community-chat.md)建设，不以这个 HTML 替代功能验收。

## 本次预览验证

2026-10-04 使用隔离的无头 Edge 打开本地 HTML，并阻断 HTTP/HTTPS 请求。已检查 1440×900、375×812、320×740 下无横向溢出，以及发送/引用/撤回、失败重试不重复、上滑时新消息不抢滚动、表情插入、页面切换保留草稿、昼夜切换、加入说明、茶杯键盘操作不自动发送、输入法组合不误发、HTML 作为文本及 2001 code point 拒绝；浏览器未报告运行异常。

这组检查是静态原型的交互验证，未验证真实网络、数据库、手机软键盘或私人阅读闭环。
