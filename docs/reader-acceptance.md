# 独立小说阅读器验收

2026-10-04。本记录针对[阅读器设计](superpowers/specs/2026-10-03-novel-reader-design.md)。首要流程是书库点击书籍 → 本书空间 → 阅读或聊天；首页推荐书籍卡另提供“继续阅读”与“继续对话”，分别直达当前书阅读页和聊天页。

## 本地合成浏览器验收

在 `client/` 运行 `npm run dev -- --host 127.0.0.1`，使用输出中的实际端口访问 `/reader.acceptance.html`。这个入口挂载真实 App，在挂载前安装合成 API：三本示例书、一节 80,000 UTF-16 单位正文、重复句、emoji、HTML 字样、长段、引用、固定聊天 SSE、断网与位置冲突。未列入清单的 `fetch` 拒绝执行，XHR 和 `sendBeacon` 被阻断；它不会请求开发后端、上传目录或模型服务。验收脚本示例：在仓库根目录运行 `node client/test/verify-reader-browser.cjs http://127.0.0.1:5173`，端口以 Vite 实际输出为准。

2026-10-04 在本机 Edge 154.0.4258.53 无头浏览器运行上述脚本，退出码 0。脚本保存截图和结构化结果在忽略版本控制的 `.superpowers/sdd/2026-10-03-novel-reader/browser/`。实际观察：

| 验收项 | 结果 |
| --- | --- |
| 从书库进入本书空间，分别进入阅读和原聊天 | 通过；本书空间先显示，未请求正文或聊天会话 |
| 首页“继续阅读”快捷入口 | 直接进入推荐书籍的阅读页，恢复已保存的文字位置，不准备聊天会话；375px、768px 首页按钮无水平溢出 |
| 80,000 单位章节滚动与请求 | 首屏仅 1 个 16,000 单位窗口；每窗与合成源文本切片相等；连续窗口无缺漏；DOM 中最多 3 窗 |
| 滚动条与反向阅读 | 直接拖动至未加载区域可请求目标窗口；反向滚动重新加载前文，始终最多 3 窗 |
| 连续跨章 | 向下滚动进入下一章，按实际可见章的正文 hash 保存；向上回看可重新加载前章末尾；预取不改变当前章节或续读记录 |
| 字号 20→28、宽度 640→480 与刷新 | 保存约 60,000 的位置，重排与刷新后测量偏差均不超过 32 个 UTF-16 单位，在可见首行内 |
| 手机与平板 | 375×812、768×1024、1440×900 的明暗主题无水平溢出；手机助手为弹层，Escape 关闭并返回焦点 |
| 阅读界面与动效 | 桌面书籍、目录、续读与工具独立圆角卡面；只有一张正文滚动卡，内部章节透明、无卡片边框；手机底部工具栏；目录、排版与助手可用 Escape 关闭，目录和助手返回触发按钮焦点；减少动态效果设置下弹层无位移或缩放 |
| 较窄与较矮的桌面窗口 | 1024×768 展开助手后正文与导航可用；1440×500 的侧栏可滚动，目录至少显示一行，续读卡可滚动进入可视区域 |
| 助手输入框 | 同书草稿保留；面板重开或宽度改变后重新测量输入框，短草稿不保留窄宽度下的过高尺寸 |
| 目录开合锚点 | 关闭侧边目录前后测得相同章节和偏移，首行间距保持不变 |
| 书房外观和聊天 | 更换背景后各入口沿用所选外观；聊天保留原布局、会话、两条消息及未发送草稿 |
| 引用与范围 | 服务端定位的引用高亮后返回原续读处；预览前后续读 revision 不变；未调用 `reading-progress` PUT |
| 冲突与断网 | 冲突暂停自动保存，需点击“使用本窗口的位置”；下一段断网保留已加载正文，重试后继续；位置断网显示失败与重试入口 |
| 滚动性能 | 测试中的连续窗口滚动未记录到 ≥50ms 的 PerformanceObserver long task；此项只反映本机合成正文和该浏览器 |

另外，正文在页面中以文本呈现，合成的 `<script>` 字样没有执行。浏览器 fixture 的 409 只验证界面行为，不能证明 PostgreSQL 中的真实并发 CAS。

## 质量门与真实数据边界

客户端和服务端默认质量门分别为 `cd client && npm run check`、`cd server && npm run check`。服务端默认 Jest 发现列表已经核对：专用 `book-reader-position.db.spec.ts` 不在默认范围。正文、引用、位置的新服务及控制器使用隔离 mock 覆盖了 owner/book、索引版本、窗口拼接、emoji 边界、无效参数和冲突。

首版客户端与服务端质量门均退出码 0。2026-10-04 阅读界面与连续跨章升级后，客户端再次通过 lint、37 个测试文件 / 143 个测试、类型检查与生产构建；本次没有修改服务端，沿用首版 64 个测试套件 / 370 个测试与生产构建结果。客户端回归覆盖加载中切换阅读/聊天、跨书的迟到成功与失败、正文变更后的显式恢复、换章保存、章节间同偏移的精确恢复、引用只高亮所属章、短章预取，以及预取期间反向滚动不淘汰可见窗口。用户执行迁移后，已通过只读检查确认本机迁移状态最新，且 `BookReadingPosition` 表存在；这不代表其他部署环境已经迁移。

续读位置以服务端确认成功为准。界面显示等待保存、保存中或同步失败时，刷新、关页或快速切换到另一册可能丢失最后未确认的位置；不会用浏览器长期保存私人位置，也不会自动覆盖其他窗口的新位置。

本轮没有由 Agent 部署迁移，没有运行 `npm run test:db:reader`，因为尚未核对独立 `*_test` 数据库与 `test_*` schema；没有运行真实用户上传/索引/模型 E2E，因为这会写真实服务并调用外部供应商。投入其他环境前，还须单独验证迁移目标与备份；真实数据库 CAS、级联及完整闭环仍未验证。
