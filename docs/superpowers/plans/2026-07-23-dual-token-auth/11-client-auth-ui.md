# CLIENT-02：注册登录界面与账号展示

**目标：** 用户无需离开当前产品流程即可注册、登录并看到当前账号状态，同时 Guest 使用不被强制中断。

**依赖：** AUTH-02、CLIENT-01。

## 范围

- 增加登录和注册 Modal 或独立 View，不强制引入 Router。
- 实现邮箱、密码、名称输入与前端基础校验。
- 接入注册、登录和 `/auth/me` 接口。
- 登录成功后写入 Auth Store。
- 侧栏增加登录入口、当前用户名称和登出入口占位。
- 使用现有暖象牙、珊瑚橙设计 Token，不建立新视觉体系。
- 显示可理解的重复邮箱、凭证错误和网络失败提示。

## 不包含

- 忘记密码、邮箱验证码、OAuth。
- 自动认领 Guest 数据。
- 401 自动刷新和服务端登出调用。

## 验收清单

- [ ] 用户可从现有界面打开登录和注册表单。
- [ ] 用户可完成注册并进入登录状态。
- [ ] 用户可使用已有账号登录。
- [ ] 表单校验和服务端错误正确显示。
- [ ] 关闭表单后仍可继续以 Guest 身份聊天。
- [ ] 登录后侧栏显示当前用户名称。
- [ ] 页面重载后能恢复并校验账号状态。
- [ ] 界面在现有桌面布局下无明显溢出或遮挡。

## 测试建议

- 登录、注册表单成功与失败交互测试。
- Auth Store 写入和 `/auth/me` 恢复测试。
- Guest 关闭登录弹窗后继续使用测试。
