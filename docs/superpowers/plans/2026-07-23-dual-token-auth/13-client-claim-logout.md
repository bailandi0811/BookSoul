# CLIENT-04：自动认领与安全登出

**目标：** 登录后自动保留当前 Guest 会话与记忆，登出后彻底隔离上一账号数据并回到新的 Guest。

**依赖：** AUTH-04、CLAIM-01、CLAIM-02、CLIENT-02、CLIENT-03。

## 范围

- 登录或注册成功后自动调用 `claim-guest`。
- 认领成功后刷新历史列表、当前会话和记忆状态。
- 认领部分失败时保留 Guest ID 和可重试状态。
- 提供明确但不惊扰用户的认领失败提示与重试入口。
- 登出时先调用服务端 `/auth/logout`，再清理本地账号状态。
- 登出后生成新的 Guest ID。
- 清空上一账号的历史、当前消息、记忆和用户缓存，避免误显。

## 不包含

- 跨设备同步 Guest 数据。
- 登录后认领 Guest 的全部历史会话。
- 管理指定登录设备。

## 状态规则

认领完全成功后才能丢弃旧 Guest ID；若返回 `partial`，保留重试所需信息，但业务请求身份仍使用已登录用户。

## 验收清单

- [ ] 跑通“Guest 聊天 → 登录 → 原会话仍在”。
- [ ] 原 Guest 记忆在登录后仍可读取和检索。
- [ ] 自动认领重复执行不会生成重复数据。
- [ ] 认领失败或部分成功时用户能看到提示并重试。
- [ ] 登出请求会在服务端吊销当前 RT。
- [ ] 登出后上一账号的历史和记忆不再显示。
- [ ] 登出后生成新 Guest，且不会继承上一账号会话。
- [ ] 已登出的 RT 无法再次刷新。

## 测试建议

- 登录后完整认领、部分失败和重试测试。
- 登出成功、网络失败和本地兜底清理测试。
- 登出前后账号数据隔离测试。
