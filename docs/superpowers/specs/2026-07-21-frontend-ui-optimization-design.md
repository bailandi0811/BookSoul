# BookSoul 前端界面优化设计

**日期：** 2026-07-21  
**状态：** 已确认  
**范围：** 仅前端 `client/`（P1 视觉+入场+对话场；P2 体验坑）

## 背景与问题

BookSoul 产品定位是「赋予书籍灵魂，与书中人物跨越时空对话」。现有前端功能完整（流式、思考态、引用、角色切换、中断），但视觉与信息架构更接近通用 AI Chat（Indigo 主色、Bot 头像、「智能体助手」文案、Inter/系统无衬线），品牌与文学沉浸感不足。

## 目标

1. 第一屏一眼是 BookSoul / 金庸对话场，而不是又一个 AI 助手。
2. 角色身份贯穿 Header、气泡、等待态与空状态。
3. 思考与引用读起来像「沉吟 / 翻书」，而不是「知识库 / 智能体」。
4. 分阶段交付：先气质与沉浸，再修体验坑。

## 方案选择

采用 **方案 3：选角入场 + 对话场重构**。

- 不做：仅换肤（方案 1，沉浸不足）。
- 不做：无入场的纯对话场（方案 2，用户已明确选 3）。

## 信息架构

两态，单应用壳（可用本地状态，P1 不强制引入路由）：

| 状态 | 职责 |
|------|------|
| `Entrance` | 品牌 + 一句文案 + 选角 +「开始对话」 |
| `Dialogue` | 角色册侧栏 + 以当前角色为中心的对话场 |

- 首次进入走入场；本地已有有效 `character` 时可直进对话。
- 对话内「更换角色」打开轻量换角面板；侧栏点角色默认开新会话（避免人格串戏），切换前可确认。

## 视觉语言：墨色书卷

### 色板（Light 为主）

| Token | 方向 |
|-------|------|
| `--background` | 暖米白纸色 + 极淡纤维/噪点 |
| `--foreground` | 近墨黑（非纯黑） |
| `--primary` | 朱砂红（印章感），替换 Indigo `#6366F1` |
| `--accent` | 黛青 / 墨绿，用于引用与角色次强调 |
| `--muted` / `--border` | 略深纸色 / 淡墨细线 |

角色区分用节制色差（黛青 / 朱砂 / 赭石）+ 名称，避免彩虹 icon 与 emoji 玩具感。

### 字体

- 品牌与角色名：中文衬线/书卷显示字（如思源宋、霞鹜文楷）。
- 对话正文：可读无衬线，保证长聊可读性。
- 在 `index.html` 正式加载字体；移除未加载的 Inter 声明。

### 刻意避免

- 紫/Indigo 渐变、强 glow、大面积玻璃拟态。
- 技术标签作为主文案（「向量检索」「智能体助手」等降级或改写）。

暗色模式：保留开关；P1 以浅色书卷为准，暗色做「夜读纸」变体。

## 入场页 `Entrance`

第一视口只做选角：

- 英雄级品牌 **BookSoul**。
- 一句支持文案（如「赋予书籍灵魂，与书中人对话」）。
- 角色：乔峰 / 段誉 / 王语嫣 / 书魂助手；点选卡片（交互容器，允许卡片）。
- 主 CTA：**开始对话**（未选时禁用或默认书魂）。
- 不做：统计条、能力罗列、技术卖点堆砌。

## 对话场 `Dialogue`

### Header

- 当前角色名（显示字大号）+ 角色短识（如「丐帮帮主」）+ 换角入口。
- BookSoul 缩小为角标，不抢角色。

### 侧栏（角色册 + 书签）

- 上：当前书（《天龙八部》）+ 角色列表（高亮当前）。
- 中：会话书签（历史）。
- 下：记忆 / 能力收进折叠；文案改为「书中见闻」「随身本事」。

### 消息与隐喻

| 现有 | 改为 |
|------|------|
| Bot + indigo 方块 | 角色印记（姓氏印章或简笔头像位） |
| 「深度思考中…」 | 「翻检书页 / 沉吟」折叠条，步骤可展开 |
| 「知识库引用」 | 「出自第 N 回」书签条 |
| 彩色建议问题卡 | 素色书签条 / 墨线列表 |
| 底栏技术免责 | 「言出有据处，皆引自原著」 |

等待文案随角色变化（如「乔峰沉吟片刻…」）。空状态：角色开场白 + 2～3 条入戏建议（邮件等技术 demo 降到「随身本事」）。

### 输入区

- 占位符随角色（「向乔峰请教…」）。
- 发送：朱砂主色；停止：墨色/朱红描边，去掉大红 SaaS 渐变。

### 动效

保留 Framer Motion 弹簧（侧栏、思考折叠、引用展开）；去掉强 glow。入场选角：轻 stagger + 纸页位移（2～3 处有意动效）。

## 换角与状态

- Store 扩展：`view: 'entrance' | 'dialogue'`，与现有 `character` / `sessionId` 对齐。
- 换角默认 `clearMessages` 开新会话；可先确认。
- 角色元数据集中：`id`、显示名、短识、色、等待文案、占位符、开场白、建议问题。

## 阶段划分

### P1（本设计主交付）

1. 墨色书卷 token + 字体。
2. 入场页 + `view` 状态。
3. 对话场重构：Header / 侧栏语义 / 气泡印记 / 思考与引用文案 / 空状态。
4. 角色元数据贯穿 UI。

### P2（体验坑）

| 问题 | 处理 |
|------|------|
| 双重 loading（typing + thinking） | 合并为一种等待态 |
| 快捷指令不更新受控 input | 走 store / setState |
| Settings / Help 空按钮 | 实做或隐藏 |
| Abort 无反馈 | 轻提示「对话已止」 |
| 时间戳用当前时间 | 用消息自身时间 |
| `index.html` title | 改为 BookSoul |
| `user@example.com` 建议问题 | 挪到随身本事示例 |

## 技术边界

- **只改** `client/` 主题、组件、文案、角色元数据。
- **不改** Agent / SSE 协议 / 后端工具逻辑（除非 P2 发现前端无法单独修复的缺口）。
- 角色视觉 P1 用印章/姓氏印 + 色；有立绘再替换。

## 主要触及文件（预期）

- `client/index.html` — title、字体
- `client/src/index.css` — token、纸感、prose
- `client/src/App.tsx` — 入场/对话切换
- `client/src/components/BookChat/**` — 壳、侧栏、气泡、输入、引用
- 新建：`Entrance`、角色元数据模块（如 `characters.ts`）
- `client/src/store/useChatStore.ts` — `view` 与换角流程

## 成功标准

1. 去掉侧栏后，第一屏仍能认出是 BookSoul。
2. 换角后 Header / 气泡 / 等待文案立刻跟角色走。
3. 引用与思考语义为「翻书 / 沉吟」，而非「知识库 / 智能体」。
4. P2 清单中的体验坑清零或明确降级（隐藏空入口）。

## 非目标

- 不做独立营销落地站多页路由体系（除非后续单独立项）。
- 不重画全套角色立绘资源管线。
- 不在本轮重构后端 RAG / MCP。
