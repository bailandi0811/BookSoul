# 书友客厅交互更新

当前用户授权：按已讨论方案和最新风景版设计稿直接实施。此文补充 2026-10-04 基线，冲突处以此文为准。

## 目标与范围

独立公共聊天室；全站只有聊天室入口和统一未读角标，没有通知铃铛、弹卡、声音或系统通知。点击入口进入最新消息；房间内提供跳到未读、查看未读 @、下一条和回到最新。只改 community 模块、聊天室组件及必要入口；书架、正文阅读、私人助手不重构。不增加依赖，不修改环境配置，不运行真实数据库迁移。

## 交互与数据

- 普通消息和 @ 同计入入口未读，一条消息算一次。只读本人实际可见的消息；页面隐藏、只点击入口、只跳转或收起提示不确认其他消息已读。
- 新成员加入时以当前事件序号为历史基线，不将入场前历史计入未读。基线之后按消息收据记录，不用最高可见序号清空中间缺口。旧客户端 throughSeq 接口保留兼容；新客户端只调用 visible-read。
- 引用和 @ 独立。回复自动加入目标成员的可删除 @ 标签；删除标签保留引用，取消引用保留标签。手动 @ 从房间成员候选选择，绑定 public memberId，不按文字昵称推断、不接受账号 userId、不做 @所有人。每条最多 10 个不同目标，自己 @ 自己不计提醒。发送及重试幂等哈希包含目标集合；没有 @ 的旧请求哈希保持原值。
- 后端保存经房间成员校验的 @ 快照，客户端不能声明昵称。撤回消息投影删除正文和 @；引用摘录继续遵守 tombstone。重放只更新数量，不自动弹出或发声。
- 未读跳转服务端按房间和当前成员过滤，在缓存外也能加载目标附近上下文。不存在目标提示用户；撤回目标仅显示撤回标记。回看历史不抢滚动，加载更早内容保留锚点，消息缓存 500、消息 DOM 100、待发 20 保持有界。
- 聊天身份使用当前账号昵称和头像；头像公开说明版本 2026-10-05，旧成员主动确认后才展示其头像。读取者必须是房间成员；头像接口只映射 public memberId 到当前 READY AVATAR，服务端代理返回 WebP，不返回 userId、assetId、objectKey 或私人签名 URL。头像删除/更新按当前资产生命周期生效，失败显示昵称首字；不读取书籍、对话、记忆或私人壁纸。

## 验收

两个包默认数据库无关检查；服务端校验拒绝非成员 @、跨房间跳转/已读/头像、幂等目标变更；客户端验证可见已读不清旧 @、身份切换隔离、重放不重复计数、删 @ 与删引用独立、缓存外跳转、撤回清摘录。隔离内存浏览器 fixture 验证桌面/手机/暗色、滚动锚点、发送和引用。真实数据库迁移、OSS头像读取、双浏览器真实 WS 和生产代理另列未验证，不以 mock 代替。
