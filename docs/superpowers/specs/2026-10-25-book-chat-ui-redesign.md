# 书籍聊天页与原文依据侧栏设计

日期：2026-10-25。本规格以最终确认的回答态与空状态设计稿为视觉基准：

- [回答态：等高原文依据侧栏](assets/book-chat-ui-redesign-v4-full-height-sources.png)
- [新对话：空状态](assets/book-chat-ui-redesign-v5-empty-state.png)

## 1. 任务契约

- **Goal：** 在保留书魂现有场景背景、暖灰纸张、圆角卡片与书卷字体的前提下，让回答和原文依据各自形成清晰区域，并隐藏内部思考步骤。
- **Done：** 桌面端具有书籍侧栏、对话区和等高原文侧栏；新对话、加载、已有引用和无引用四种状态可独立识别；引用随所选回答切换；窄屏使用对话框式底部面板；相关测试与客户端质量门通过。
- **Scope：** 修改书籍聊天页组件、原文引用展示、相关样式与回归测试。
- **保持不变：** BM25、RAG、向量检索、服务端权限与防剧透过滤、SSE 事件、引用数据结构和阅读器定位能力。

## 2. 页面结构

桌面宽屏支持三列布局：左侧书籍导航，中间对话面板，右侧原文依据面板。原文依据默认收起；用户打开后，对话和原文面板等高。引用不作为聊天消息插入回答正文。

新对话在中央展示一句说明和三个通用问题入口。右侧保留完整高度，并显示“提问后，这里会显示原文依据”。问题建议必须适用于任意书籍，不使用设计稿示例书的专有内容。

## 3. 原文依据状态

| 状态 | 展示内容 |
| --- | --- |
| 尚未提问 | 空状态说明，不生成虚构引用 |
| 正在回答且尚无引用 | 中性骨架占位，不显示检索词、工具调用或推理步骤 |
| 回答有引用 | 显示本次回答的引用数量、章节、标题、摘录和“在正文中查看” |
| 回答无引用 | 明确说明当前阅读范围内没有可直接引用的原文 |

默认选择最近一条助手回答。点击任意回答下方的“N 处原文依据”后，侧栏展开并切换到该回答携带的引用快照。已有多条引用时，以约 180ms 的间隔逐张显现；这是客户端展示节奏，不改变服务端检索和引用结果。界面不得显示 `chunkId`、分数或其他检索元数据。

## 4. 交互与响应式

- 点击引用卡片的“在正文中查看”复用现有阅读器定位流程；定位失败时在侧栏显示可行动错误。
- 关闭桌面侧栏后，对话区扩展；可从回答的引用按钮或页头书本按钮重新打开。
- 1180px 以下不常驻第三列。点击引用入口后使用现有可访问对话框承载原文面板；手机端停靠在屏幕底部。
- 侧栏开合和回答间切换使用约 200ms 的淡入与位移动画；系统启用减少动态效果时停止非必要动画。
- 流式阶段只允许展示“正在查找已读原文”等产品状态，不提供可展开的思考或检索步骤。

## 5. 验收

1. 新会话不含用户或助手消息，中央与右侧均显示对应空状态。
2. SSE 引用到达后只写入所属助手消息；选择不同回答时，右侧只显示该回答的引用。
3. 页面不渲染 `thinkingSteps` 的具体文本，失败与停止状态仍可见。
4. 引用正文不出现在回答卡片内部；回答下方只保留引用数量入口。
5. 运行相关 Vitest，并执行 `cd client && npm run check`。
